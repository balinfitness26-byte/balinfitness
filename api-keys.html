Getting an API key

Use an AI company's own API directly with Balin — no server of your own needed. You're billed by that company, based on how much you use it and which model you pick.

This costs real money, pay-as-you-go. It's billed to you by whichever company you choose — not by Balin, and not a fixed subscription. More capable ("smarter") models cost more per use than smaller, faster ones. Most people's day-to-day use with Balin (a few short messages a day) costs very little — often well under a dollar a month on an efficient model — but it's worth watching if you set up alerts or a spending cap, which every provider below lets you do.

Pick a provider

Any of these speak the same "OpenAI-compatible" format Balin expects, so the setup steps are the same for all of them — just a different base address.

Prices and free-tier limits change often — check each provider's own pricing page before committing, especially if you plan to use a top-tier model.

1. Create an account and get a key

  1. Open the provider's site from the table above and sign up (usually just email or Google sign-in).
  2. Find API keys in their dashboard (usually under account/developer settings) and create a new key.
  3. Copy it immediately — most providers only show the full key once.
  4. Add billing if the provider requires it (OpenAI and most others need a card on file before the key works, even for small usage — this is normal). Set a monthly spending cap here if they offer one; it's the easiest way to avoid surprises.

2. Pick a model

Each provider lists its available model names on their docs/pricing page. In general: smaller/faster models (often with "mini," "flash," or "small" in the name) are cheap and plenty good for everyday chat and reminders; the largest "flagship" models cost more per message but reason better on complex questions. A sensible starting point for most people:

  • OpenAI: gpt-4o-mini
  • Groq: llama-3.3-70b-versatile
  • Gemini: gemini-2.0-flash

3. Connect it in Balin

Settings → AI engine → Use an API key, then:

  • Base address: from the table above
  • API key: the key you copied in step 1
  • Model: the exact model name from step 2

Tap Save & test. If it connects, you're set — Balin now talks straight to that provider with your key, billed to your own account there.
