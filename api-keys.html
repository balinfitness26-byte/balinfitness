Get an API key for Balin

For people who'd rather pay a company directly for AI than run their own server or use Balin's built-in one.

Balin's "Use an API key" option works with any company whose API speaks the common OpenAI chat format — which, these days, is most of them. Pick one below, sign up, create a key, and paste it (along with that provider's base address) into Balin → Settings → AI engine → Use an API key.

Your key is saved on your phone only. Balin sends it straight to whichever company you chose, the same way any app would — Balin's developer never sees it or the conversations that use it.

About model names: every company below retires old models and adds new ones over time, so a model name printed on this page can stop working later (this happened with an earlier version of this page, which listed a Gemini model that Google has since removed). Once you've entered your base address and key in Balin, tap Browse available models right there in Settings → AI engine — Balin asks the provider directly, right then, which models work for your key today, and lets you tap one in instead of typing a name that might be out of date. The model names below are just a starting point if you'd rather type one yourself.

1. Pick a provider and get a key

OpenAI

The company behind ChatGPT. Reliable, widely used, usage-based pricing.

  1. Go to platform.openai.com and create an account.
  2. Add a payment method under Billing (API usage is separate from any ChatGPT subscription you may have).
  3. Go to API keys, click Create new secret key, and copy it immediately — it's shown only once.
Base addresshttps://api.openai.com/v1
Model to try (if typing one by hand)gpt-4o-mini (fast and inexpensive)

Groq

Extremely fast responses, generous free tier, smaller model selection.

  1. Go to console.groq.com and sign in with Google or GitHub.
  2. API Keys → Create API Key, name it, copy it.
Base addresshttps://api.groq.com/openai/v1
Model to try (if typing one by hand)llama-3.3-70b-versatile

Together AI

Wide choice of open-source models, pay-as-you-go with a small free credit to start.

  1. Go to api.together.ai and sign up.
  2. Settings → API Keys, copy the default key or create a new one.
Base addresshttps://api.together.xyz/v1
Model to try (if typing one by hand)meta-llama/Llama-3.3-70B-Instruct-Turbo

Mistral

French AI lab, their own frontier models, a free tier for light personal use.

  1. Go to console.mistral.ai and create an account.
  2. API Keys → Create new key, copy it.
Base addresshttps://api.mistral.ai/v1
Model to try (if typing one by hand)mistral-small-latest

OpenRouter

One key, one bill, access to dozens of other companies' models (including many free ones) through a single address — a good choice if you want to try several without juggling separate accounts.

  1. Go to openrouter.ai and sign in.
  2. Keys → Create Key, copy it.
Base addresshttps://openrouter.ai/api/v1
Model to try (if typing one by hand)meta-llama/llama-3.3-70b-instruct (or add :free for a no-cost option)

Google Gemini

Google's own models, reachable through their OpenAI-compatible address.

  1. Go to aistudio.google.com/apikey and sign in with a Google account.
  2. Create API key, copy it.
Base addresshttps://generativelanguage.googleapis.com/v1beta/openai
Model to try (if typing one by hand)gemini-3.8-flash — but Google renames/retires these faster than most, so Browse available models is especially worth using here

2. Entering it in Balin

Open Balin → Settings → AI engine → Use an API key, then fill in:

  • Base address — the exact address from the table above for the provider you chose.
  • API key — the key you just copied.
  • Model — tap Browse available models once the address and key above are filled in, and pick one from the live list Balin gets back from the provider. This is the reliable way to fill this field, since it always reflects what that provider currently offers for your key — not a name printed on a page that can go stale.

Tap Save & test — Balin sends a small test message and tells you right away if the key, address, or model is wrong.

Costs: every provider above bills (or rate-limits) based on your own usage. Balin's developer has no visibility into or control over what you're charged — check each provider's own pricing page before you start, and keep an eye on usage if you're cost-conscious.
