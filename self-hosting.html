Set up your own AI server

Every AI feature in Balin — Balin himself, motivation, reminders, diet advice, and voice — runs through an AI server you point the app at. You don't need to use a company's paid API; you can run a free, private server yourself on a spare computer or a cloud VM. This guide walks through the easiest option: Ollama.

Your data never has to leave a server you control. Nothing in this setup requires paying anyone.

1. Install Ollama

Ollama runs AI models locally and exposes them over a simple API — this is what Balin's "Another server" option expects.

  • Windows / Mac / Linux: download from ollama.com/download and install it.

2. Download a model

Open a terminal (Command Prompt / PowerShell / Terminal) and run:

ollama pull llama3.2

This downloads a small, fast model that runs well even on modest hardware. You can swap in a larger model later if your machine can handle it.

3. Allow outside connections (optional, for your phone to reach it)

By default Ollama only listens on the same machine. To let your phone connect to it over your home network or the internet, you need to bind it to all network interfaces:

  • Windows: set an environment variable OLLAMA_HOST to 0.0.0.0:11434, then restart Ollama.
  • Mac/Linux: run OLLAMA_HOST=0.0.0.0:11434 ollama serve
If your phone and server are on the same Wi-Fi network, you can use your computer's local IP address (e.g. http://192.168.1.23:11434) directly — no extra setup needed beyond this step.

4. Find your server address

If you're only using it at home over Wi-Fi, your server address is your computer's local IP and port, for example:

http://192.168.1.23:11434

To find your local IP: on Windows run ipconfig and look for "IPv4 Address"; on Mac/Linux run ifconfig or ip addr.

If you want to reach it from outside your home network (e.g. mobile data), you'll need to either port-forward on your router, or use a tunneling service such as Tailscale or ngrok to get a stable, reachable address. Balin needs an https:// address if you're using a tunnel like ngrok.

5. Enter it in Balin

  1. Open Balin → Settings → AI engine.
  2. Choose Another server.
  3. Enter your server address (e.g. http://192.168.1.23:11434 or your tunnel's https:// URL).
  4. Leave Access key blank (Ollama doesn't require one by default) unless you've set up authentication yourself.
  5. Model field: type llama3.2 (or whatever model you pulled).
  6. Tap Save & test.

Keeping it running

Your computer needs to be on and Ollama running whenever you want Balin's AI features to work. If that's inconvenient, consider running Ollama on a cheap always-on device (an old laptop, a Raspberry Pi 4/5 with enough RAM, or a small cloud VM) instead of your main computer.

Need help? This is a self-hosted, optional setup — Balin works fine without it if you'd rather use an API key instead.
